# DESIGN SYSTEM — WEDDING INVITATION

## Bambang Ceper & Imroatus Angel

---

# 1. Design Direction

Website merupakan digital wedding invitation dengan konsep:

**Elegant Blue Rustic — Botanical Wedding**

Visual harus terasa:

- elegant
- romantic
- intimate
- premium
- soft
- classic
- botanical
- sophisticated
- feminine tetapi tetap memiliki karakter maskulin
- seperti undangan pernikahan premium yang dikonversi menjadi website

Referensi visual utama menggunakan konsep wedding invitation dengan:

- background ivory
- floral botanical illustration
- foliage berwarna biru
- frame foto oval
- typography serif
- typography script untuk nama pasangan
- ornament floral yang mengelilingi konten
- layout portrait yang menyerupai kartu undangan
- whitespace yang cukup luas

Jangan membuat tampilan seperti:

- dashboard
- SaaS
- corporate website
- portfolio
- ecommerce
- blog
- landing page startup

Website harus langsung terasa sebagai:

**Premium Digital Wedding Invitation.**

---

# 2. Design Reference

Gunakan gambar referensi yang diberikan sebagai inspirasi utama untuk:

- komposisi floral
- frame foto
- penggunaan warna biru
- background paper
- hierarchy typography
- penggunaan whitespace
- bentuk portrait image
- ornamen botanical
- nuansa wedding invitation

Jangan menyalin desain secara identik.

Buat interpretasi UI modern berdasarkan referensi tersebut.

---
